KÜLLERİN KRALLIĞI — Web RPG

OYNAMA:
1) index.html dosyasını Chrome/Safari/Firefox ile aç.
2) İnternet gerekmez.
3) Kayıt tarayıcı localStorage içinde otomatik tutulur.

YAYINLAMA:
- itch.io: HTML Game oluştur, bu ZIP'i yükle, Mobile Friendly seç.
- GitHub Pages: index.html dosyasını repo köküne koyup Pages'i etkinleştir.
- Her statik hosting servisiyle çalışır.

İçerik:
- 4 sınıf
- Can/mana/dayanıklılık/yozlaşma/insanlık
- Seviye/XP/altın
- Envanter
- Yetenek sistemi
- Görev günlüğü
- Harita
- Otomatik kayıt + kayıt dışa aktarma
- Dallanan karanlık hikâye
- Rastgele hasarlı tur tabanlı savaş
- 4 ana düşman/boss
- Farklı ve gizli sonlar
- Mobil responsive arayüz
- Harici asset veya AI görseli gerektirmez; stilize CSS sahne sanatı kullanır.
